# Portfolio

Personal site of Uppala Sri Chaitanya. Astro + Preact (React compat) + Tailwind v4 + Motion.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # type-check + static build to dist/
npm run media     # rebuild public/media from assets/ (needs ffmpeg)
```

- Copy and data: `src/content/projects.ts`
- Raw uploads live in `assets/` and are never served; optimised outputs are in `public/media/`.
- Design and build plan: `docs/PLAN.md`
